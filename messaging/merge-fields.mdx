A merge field is a placeholder that is replaced with a contact's information when the message is sent. For example, if you use Hi `{{contact.first_name}}`, each person will receive their own name, such as Hi Priya or Hi Sam.

## How to add one

In any text box that supports merge fields, type `@`. A list opens — pick a field and its `{{token}}` is added to your text box for you. No need to type it yourself.

## Where you can use them

- The [Inbox](/messaging/live-chat) reply box
- [Quick replies](/core-setup/canned-replies)
- [Campaigns](/messaging/campaigns)
- [WhatsApp template](/messaging/whatsapp-templates) variable values
- [Sending a template to one contact](/contacts/managing-contacts#actions-on-a-single-contact) from a contact row
- [Automation flows](/automation/flow-builder)

## Available fields

<AccordionGroup>
<Accordion title="Contact fields">
  Contact ID, First Name, Last Name, Full Name, Email, Phone Number, Display Name, Contact Status, Contact Source, and Assigned To.
</Accordion>

<Accordion title="Custom fields">
  Every active [customer field](/core-setup/custom-fields) you create shows up.
</Accordion>

<Accordion title="Team fields">
  Team Name, Team Email, Team Domain, and Team Subdomain.
</Accordion>

<Accordion title="Shopify order fields">
  Available when you have [connected your Shopify store](/shopify/connect-your-store). They use the contact's most recent order or cart: Order Number, Order Date, Order Total, Subtotal, Shipping Price, Total Tax, Currency, Discount Code, Discount Amount, Items Summary, Payment Status, Payment Method, Fulfillment Status, Shipment Status, Tracking Number, Tracking URL, Cart Recovery Link, Shipping City, Shipping Address, and Order Note.
</Accordion>
</AccordionGroup>

## Automation fields

[Automation flows](/automation/flow-builder) add their own fields to the picker. A flow can use answers the customer gave earlier in the chat.

<Warning>
  If a contact doesn't have a value for a merge field, that part stays blank. The message is still sent. You cannot set a default value.
</Warning>
