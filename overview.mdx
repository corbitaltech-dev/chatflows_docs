## Get started

<Steps>
  <Step title="Create an API key">
    Go to [Setup → Developer API Keys](/core-setup/api-keys) and click **Add Token**. Enter a name, select the permissions it needs, and copy the key. The key is shown only once.
  </Step>
  <Step title="Connect your business system">
    Add your API key and the base URL below to your other business system.

    ```text Base URL
    https://app.chatflows.io/api/v1
    ```
  </Step>
  <Step title="Test the connection">
    Send a request to [Ping](/api-reference/auth-&-account/ping). A successful response confirms your API key is set up correctly.
  </Step>
</Steps>

## Permissions and security

- **Choose only the permissions you need.** Each API key has its own permissions, such as viewing customers or sending messages. Select only what your business system uses.
- **Keep your API keys secure.** Anyone who has a key can access your workspace data. Store it safely and never share it in emails, chats or public places.
- **Revoke keys you no longer use.** If a key is no longer needed or may have been exposed, revoke it from the [Developer API Keys](/core-setup/api-keys) page. It stops working immediately.

## Error codes

| Code | Meaning | What to do |
|---|---|---|
| `401` | The API key is missing, invalid or expired. | Check the key, or create a new one. |
| `402` | The workspace has no active subscription. | Review [Plan & Billing](/billing/plan-and-billing). |
| `403` | The API key doesn't have the required permission. | Create a key with the missing permission. |
| `404` | The record or address doesn't exist. | Check the ID or URL. |
| `422` | Some data is missing or invalid. | The error message names the field to fix. |
| `429` | Too many requests, or the monthly limit is reached. | Wait and retry. |
